HTML DASAR

1. Pengenalan HTML

HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk membuat struktur sebuah halaman website.

Fungsi HTML

  • Membuat judul dan paragraf.
  • Menampilkan gambar dan video.
  • Membuat tautan (link).
  • Membuat tabel dan formulir.
  • Menyusun struktur halaman website.

Contoh HTML

<h1>Halo Dunia!</h1>
<p>Saya sedang belajar HTML.</p>
Hasil:

Halo Dunia!

Saya sedang belajar HTML.

2. Struktur Dasar HTML

Setiap dokumen HTML memiliki struktur dasar yang terdiri dari beberapa elemen utama. 

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Website Saya</title>
</head>
<body>

    <h1>Halo Dunia</h1>
    <p>Website pertama saya.</p>

</body>
</html>

Penjelasan

  • DOCTYPE: Menyatakan dokumen menggunakan HTML5.
  • html: Elemen utama dokumen HTML.
  • head: Menyimpan informasi halaman.
  • title: Menentukan judul tab browser.
  • body: Menyimpan konten yang ditampilkan.

3. Tag dan Elemen HTML

Tag adalah penanda yang digunakan untuk membentuk elemen HTML. 

<p>Ini sebuah paragraf.</p>

Tag pembuka adalah <p>, sedangkan tag penutup adalah </p>.

Contoh tag lainnya

  • <h1> : Judul utama.
  • <p> : Paragraf.
  • <div> : Container.
  • <span> : Elemen inline.
  • <br> : Baris baru.

4. Heading dan Paragraf

Heading digunakan untuk membuat judul, sedangkan paragraf digunakan untuk teks. 

<h1>Judul Utama</h1>
<h2>Sub Judul</h2>
<h3>Judul Bagian</h3>

<p>Ini adalah sebuah paragraf.</p>

Judul Utama

Sub Judul

Judul Bagian

Ini adalah sebuah paragraf.

Selain paragraf, HTML punya banyak elemen untuk memberi makna dan penekanan pada teks. 

<p>Teks <strong>penting</strong></p>
<p>Teks <em>miring</em></p>
<p>Teks <mark>ditandai</mark></p>
<p><small>Teks kecil</small></p>
<p>H<sub>2</sub>O dan x<sup>2</sup></p>

<blockquote>
    Kutipan panjang ditulis di sini.
</blockquote>

<hr>

  • strong: Teks penting (tebal).
  • em: Penekanan (miring).
  • mark: Menyorot teks.
  • hr: Garis pemisah horizontal.

6. Link dan Gambar

Tag anchor digunakan untuk membuat tautan. Tag img digunakan untuk menampilkan gambar. 

<a href="https://google.com">
    Buka Google
</a>

<img src="gambar.jpg"
     alt="Gambar contoh">

Atribut penting

  • href: Alamat tujuan tautan.
  • src: Lokasi file gambar.
  • alt: Teks alternatif gambar.

Membuka link di tab baru

<a href="https://google.com"
   target="_blank"
   rel="noopener">
    Buka di tab baru
</a>

7. List dan Tabel

HTML memiliki dua jenis list yang umum digunakan.

<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>

<ol>
    <li>Belajar HTML</li>
    <li>Belajar CSS</li>
</ol>

Tabel

Untuk tabel, gunakan elemen table, tr, th, dan td. Bagian tabel dapat dikelompokkan dengan thead, tbody, dan tfoot. 

<table>
    <thead>
        <tr>
            <th>Nama</th>
            <th>Kelas</th>
            <th>Nilai</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Andi</td>
            <td>X PPLG</td>
            <td>90</td>
        </tr>
        <tr>
            <td>Budi</td>
            <td>X PPLG</td>
            <td>85</td>
        </tr>
    </tbody>
</table>
Hasil:
NamaKelasNilai
AndiX PPLG90
BudiX PPLG85

Menggabungkan sel

<td colspan="2">Gabung 2 kolom</td>
<td rowspan="2">Gabung 2 baris</td>
  • colspan: Menggabungkan beberapa kolom.
  • rowspan: Menggabungkan beberapa baris.

8. Atribut Global

Atribut memberi informasi tambahan pada elemen. Atribut global bisa dipakai di hampir semua elemen HTML. 

<p id="intro"
   class="teks-besar"
   style="color: blue;"
   title="Ini tooltip"
   lang="id">
    Halo!
</p>

<p hidden>Paragraf ini disembunyikan.</p>
  • id: Nama unik untuk satu elemen.
  • class: Nama kelompok, boleh dipakai banyak elemen.
  • style: CSS langsung pada elemen (inline).
  • title: Teks tooltip saat kursor diarahkan.
  • lang: Bahasa konten elemen.
  • hidden: Menyembunyikan elemen.

Satu halaman tidak boleh punya dua elemen dengan id yang sama.

9. Elemen Block dan Inline

Elemen HTML dibagi menjadi dua jenis tampilan dasar.

  • Block: Selalu mulai di baris baru dan mengambil lebar penuh. Contoh: div, p, h1, ul.
  • Inline: Tetap satu baris dan hanya selebar isinya. Contoh: span, a, strong, img. 
<div>Block 1</div>
<div>Block 2</div>

<span>Inline 1</span>
<span>Inline 2</span>
Hasil:
Block 1
Block 2
Inline 1 Inline 2

10. Form HTML

Form digunakan untuk menerima input atau data dari pengguna. 

<form>
    <label>Nama:</label>
    <input type="text">

    <button type="submit">
        Kirim
    </button>
</form>

11. Tipe Input Form

Elemen input punya banyak tipe sesuai jenis data yang diinginkan. 

<form>
    <label for="email">Email:</label>
    <input type="email" id="email"
           placeholder="nama@email.com" required>

    <label for="sandi">Password:</label>
    <input type="password" id="sandi">

    <label for="usia">Usia:</label>
    <input type="number" id="usia" min="1" max="100">

    <label>
        <input type="checkbox"> Saya setuju
    </label>

    <label><input type="radio" name="jk" value="L"> Laki-laki</label>
    <label><input type="radio" name="jk" value="P"> Perempuan</label>

    <select>
        <option>Pilih kelas</option>
        <option>X</option>
        <option>XI</option>
    </select>

    <textarea rows="4" placeholder="Pesan"></textarea>

    <button type="submit">Kirim</button>
</form>

Atribut penting pada input

  • placeholder: Teks petunjuk di dalam input.
  • required: Input wajib diisi.
  • min / max: Batas nilai angka.
  • name: Nama data saat form dikirim. Radio dengan name sama menjadi satu grup.
  • for pada label: Dihubungkan ke id input agar label bisa diklik.

12. Semantic HTML

Semantic HTML adalah penggunaan elemen HTML yang memiliki arti atau fungsi khusus. 

<header>Bagian atas</header>
<nav>Navigasi</nav>
<main>
    <article>Konten utama</article>
    <aside>Informasi tambahan</aside>
</main>
<footer>Bagian bawah</footer>

Semantic HTML membantu browser dan teknologi pembaca layar memahami struktur halaman.

13. Audio dan Video

HTML menyediakan elemen audio dan video untuk menampilkan media. 

<audio controls>
    <source src="musik.mp3" type="audio/mpeg">
</audio>

<video controls width="400">
    <source src="video.mp4" type="video/mp4">
</video>

14. Iframe

Iframe digunakan untuk menyematkan halaman atau konten dari sumber lain. 

<iframe
    src="https://example.com"
    width="400"
    height="250"
    title="Contoh halaman">
</iframe>

15. Entity dan Komentar

Karakter seperti < dan > dipakai oleh HTML sendiri. Untuk menampilkannya sebagai teks biasa, gunakan HTML entity. 

&lt;   → <
&gt;   → >
&amp;  → &
&copy; → ©
&nbsp; → spasi yang tidak terputus

Komentar

Komentar tidak ditampilkan di halaman, hanya catatan untuk pembuat kode. 

<!-- Ini komentar, tidak tampil di browser -->
<p>Teks ini tampil.</p>

16. Meta Tag dan Favicon

Meta tag berada di dalam head dan menyimpan informasi tentang halaman. 

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <meta name="description"
          content="Belajar HTML, CSS, dan JavaScript">
    <link rel="icon" href="favicon.ico">
    <title>Judul Halaman</title>
</head>
  • charset: Pengodean karakter (UTF-8 mendukung semua huruf).
  • viewport: Agar tampilan pas di layar HP.
  • description: Ringkasan halaman untuk mesin pencari.
  • favicon: Ikon kecil di tab browser.

17. Menghubungkan CSS dan JavaScript

Ada tiga cara menambahkan CSS, dan dua cara menambahkan JavaScript ke HTML. 

<!-- CSS eksternal (disarankan) -->
<link rel="stylesheet" href="style.css">

<!-- CSS internal -->
<style>
    p { color: blue; }
</style>

<!-- CSS inline -->
<p style="color: blue;">Teks</p>

<!-- JavaScript eksternal, di akhir body -->
<script src="script.js"></script>

<!-- JavaScript internal -->
<script>
    console.log("Halo!");
</script>

Letakkan script di akhir body (atau tambahkan atribut defer) agar elemen HTML sudah termuat sebelum JavaScript dijalankan.

18. Path File

Path adalah alamat lokasi file, dipakai pada href dan src. 

<!-- file di folder yang sama -->
<img src="foto.jpg">

<!-- file di dalam subfolder -->
<img src="gambar/foto.jpg">

<!-- naik satu folder ke atas -->
<img src="../foto.jpg">

<!-- alamat lengkap (absolut) -->
<img src="https://contoh.com/foto.jpg">
  • Relatif: Dihitung dari lokasi file HTML saat ini.
  • Absolut: Alamat lengkap, termasuk domain.
  • ../ artinya naik satu folder.
CSS DASAR

19. Pengenalan CSS

CSS (Cascading Style Sheets) digunakan untuk mengatur tampilan dan desain halaman website.

Fungsi CSS

  • Mengatur warna teks dan background.
  • Mengatur ukuran elemen.
  • Mengatur jarak antar elemen.
  • Membuat layout website.
  • Membuat animasi dan responsivitas.
h1 {
    color: blue;
    font-size: 30px;
}

20. CSS Selector

Selector menentukan elemen HTML yang akan diberikan style. 

/* Element selector */
p {
    color: red;
}

/* Class selector */
.judul {
    color: blue;
}

/* ID selector */
#utama {
    background: yellow;
}

/* Grouping selector */
h1, h2, h3 {
    font-family: Arial;
}

/* Descendant selector */
nav a {
    color: white;
}

21. Color dan Background

body {
    background-color: #f1f5f9;
}

h1 {
    color: #2563eb;
}

.kotak {
    background-color: rgb(37, 99, 235);
    color: rgba(255, 255, 255, 0.9);
}

CSS mendukung warna dengan nama, HEX, RGB, dan format warna lainnya.

22. Tipografi

Tipografi mengatur tampilan teks seperti jenis huruf, ukuran, dan jarak. 

p {
    font-family: Arial, sans-serif;
    font-size: 18px;
    font-weight: bold;
    font-style: italic;
    line-height: 1.6;
    letter-spacing: 1px;
    text-align: center;
    text-decoration: underline;
    text-transform: uppercase;
}
  • font-family: Jenis huruf, tulis beberapa sebagai cadangan.
  • font-size: Ukuran huruf.
  • font-weight: Ketebalan huruf.
  • line-height: Tinggi baris, memudahkan membaca.
  • text-align: Rata teks (left, center, right, justify).
  • text-transform: Mengubah huruf besar atau kecil.

23. Satuan CSS

Nilai ukuran di CSS memakai satuan. Ada satuan tetap dan satuan relatif. 

.contoh {
    width: 300px;      /* piksel, ukuran tetap */
    font-size: 1.2rem; /* relatif ke ukuran font root */
    padding: 2em;      /* relatif ke font elemen itu */
    height: 50vh;      /* 50% tinggi layar */
    max-width: 80%;    /* persen dari elemen induk */
}
  • px: Piksel, ukuran tetap.
  • %: Persen dari ukuran elemen induk.
  • em: Relatif ke ukuran font elemen.
  • rem: Relatif ke ukuran font elemen html.
  • vw / vh: 1% lebar / tinggi layar.

24. CSS Box Model

Box Model menjelaskan bagaimana ukuran dan jarak sebuah elemen dihitung.

  • Content: Isi elemen.
  • Padding: Jarak isi ke border.
  • Border: Garis tepi elemen.
  • Margin: Jarak luar elemen.
.kotak {
    width: 200px;
    padding: 20px;
    border: 2px solid blue;
    margin: 15px;
}

/* Agar padding dan border tidak menambah lebar */
* {
    box-sizing: border-box;
}

25. CSS Display

Properti display menentukan bagaimana sebuah elemen ditampilkan. 

.a { display: block; }        /* satu baris penuh */
.b { display: inline; }       /* mengalir bersama teks */
.c { display: inline-block; } /* sejajar, tapi bisa diatur ukurannya */
.d { display: none; }         /* disembunyikan sepenuhnya */
.e { display: flex; }         /* layout fleksibel */
.f { display: grid; }         /* layout grid */

display: none menghilangkan elemen dari tata letak, sedangkan visibility: hidden hanya menyembunyikan tampilan tetapi ruangnya tetap ada.

26. Flexbox

Flexbox digunakan untuk mengatur posisi dan susunan elemen dalam sebuah container. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}
  • flex-direction: Arah susunan (row atau column).
  • justify-content: Perataan di sumbu utama.
  • align-items: Perataan di sumbu silang.
  • flex-wrap: Boleh turun baris atau tidak.

27. CSS Grid

CSS Grid digunakan untuk membuat tata letak berbasis baris dan kolom. 

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}

28. CSS Position

Position mengatur posisi suatu elemen dalam halaman website. 

.box {
    position: relative;
    top: 10px;
    left: 20px;
}
  • static: Posisi normal (bawaan).
  • relative: Bergeser dari posisi normalnya.
  • absolute: Diposisikan terhadap induk yang punya position.
  • fixed: Menempel pada layar.
  • sticky: Menempel saat di-scroll sampai batas tertentu.

29. Z-index dan Overflow

z-index mengatur elemen mana yang berada di depan saat saling menumpuk. Angka lebih besar berada lebih depan, dan hanya berfungsi pada elemen yang punya position selain static. 

.depan {
    position: absolute;
    z-index: 10;
}

.belakang {
    position: absolute;
    z-index: 1;
}

Overflow

overflow mengatur isi yang melebihi ukuran elemennya. 

.kotak {
    width: 200px;
    height: 100px;
    overflow: auto; /* visible | hidden | scroll | auto */
}
  • visible: Isi meluber keluar (bawaan).
  • hidden: Isi yang berlebih dipotong.
  • scroll: Selalu ada scrollbar.
  • auto: Scrollbar muncul saat dibutuhkan.

30. Responsive Design

Responsive Design membuat website dapat menyesuaikan ukuran layar perangkat. 

@media (max-width: 600px) {
    .container {
        grid-template-columns: 1fr;
    }
}

Pastikan meta viewport sudah ada di head agar media query bekerja di HP.

31. Pseudo-class dan Pseudo-element

Pseudo-class memilih elemen berdasarkan keadaan tertentu. Pseudo-element menargetkan bagian tertentu dari elemen. 

button:hover {
    background: blue;
}

p::first-letter {
    font-size: 30px;
}

p::selection {
    background: yellow;
}

32. Transition dan Animation

Transition membuat perubahan style lebih halus. Animation memungkinkan gerakan yang lebih kompleks. 

.box {
    transition: 0.3s;
}

.box:hover {
    transform: scale(1.1);
}

@keyframes bergerak {
    from { transform: translateX(0); }
    to { transform: translateX(100px); }
}

.bola {
    animation: bergerak 2s infinite alternate;
}

33. CSS Variable

CSS Variable menyimpan nilai yang bisa dipakai berulang kali. Cukup ubah di satu tempat, semua pemakaiannya ikut berubah. 

:root {
    --warna-utama: #2563eb;
    --jarak: 16px;
}

button {
    background: var(--warna-utama);
    padding: var(--jarak);
}

h1 {
    color: var(--warna-utama);
}
  • Nama variabel diawali dua tanda hubung (--).
  • :root membuat variabel bisa dipakai di seluruh halaman.
  • Dipanggil dengan fungsi var().
JAVASCRIPT DASAR

34. Pengenalan JavaScript

JavaScript adalah bahasa pemrograman yang membuat website menjadi interaktif.

Fungsi JavaScript

  • Membuat tombol interaktif.
  • Mengolah data pengguna.
  • Membuat validasi form.
  • Mengubah konten HTML.
  • Membuat aplikasi web.
alert("Halo WebLearn!");

35. Variabel

Variabel digunakan untuk menyimpan data yang dapat digunakan dalam program. 

let nama = "Budi";
const umur = 17;
var kelas = "PPLG";

console.log(nama);
  • let: Variabel yang nilainya bisa diubah.
  • const: Variabel yang tidak bisa di-assign ulang.
  • var: Cara deklarasi variabel lama.

36. Tipe Data

let nama = "Andi"; // String
let umur = 17; // Number
let aktif = true; // Boolean
let nilai = null; // Null
let kosong; // Undefined

console.log(typeof nama); // "string"

37. Operator

Operator digunakan untuk melakukan operasi terhadap data. 

let a = 10;
let b = 5;

console.log(a + b);   // 15
console.log(a > b);   // true
console.log(a === b); // false

// Operator logika
console.log(a > 5 && b < 10); // true (dan)
console.log(a < 5 || b < 10); // true (atau)
console.log(!true);           // false (bukan)

Gunakan === (sama persis, termasuk tipe data) daripada ==.

38. Template Literal

Template literal memakai tanda backtick (`) sehingga variabel dapat disisipkan langsung ke dalam teks dengan ${}. 

let nama = "Andi";
let umur = 17;

// Cara lama
console.log("Nama: " + nama + ", umur: " + umur);

// Template literal
console.log(`Nama: ${nama}, umur: ${umur}`);
console.log(`Tahun depan: ${umur + 1}`);

Template literal juga mendukung teks yang terdiri dari beberapa baris.

39. Conditional

Conditional digunakan untuk menjalankan kode berdasarkan kondisi tertentu. 

let nilai = 85;

if (nilai >= 90) {
    console.log("Sangat baik");
} else if (nilai >= 75) {
    console.log("Lulus");
} else {
    console.log("Tidak lulus");
}

40. Switch

switch membandingkan satu nilai dengan beberapa kemungkinan, lebih rapi daripada banyak else if. 

let hari = 3;

switch (hari) {
    case 1:
        console.log("Senin");
        break;
    case 2:
        console.log("Selasa");
        break;
    case 3:
        console.log("Rabu");
        break;
    default:
        console.log("Hari lain");
}

Jangan lupa break, kalau tidak, kode di case berikutnya ikut berjalan.

41. Looping

Looping digunakan untuk menjalankan kode secara berulang. 

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

// Looping pada array
let buah = ["Apel", "Jeruk"];

for (let item of buah) {
    console.log(item);
}

42. While dan Do While

while mengulang kode selama kondisinya benar. Cocok saat jumlah pengulangan tidak diketahui di awal. 

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

// do...while: dijalankan minimal satu kali
let j = 10;

do {
    console.log(j);
    j++;
} while (j < 5);
  • break: Menghentikan perulangan.
  • continue: Melewati satu putaran.

Pastikan kondisi akhirnya akan tercapai, kalau tidak terjadi perulangan tanpa akhir (infinite loop).

43. Function

Function adalah blok kode yang dapat dipanggil untuk menjalankan tugas tertentu. 

function sapa() {
    console.log("Halo!");
}

sapa();

// Dengan parameter dan nilai kembalian
function tambah(a, b) {
    return a + b;
}

console.log(tambah(2, 3)); // 5

44. Arrow Function

Arrow Function adalah cara penulisan function menggunakan tanda panah. 

const sapa = () => {
    console.log("Halo WebLearn!");
};

sapa();

// Versi singkat
const kali = (a, b) => a * b;

console.log(kali(3, 4)); // 12

45. Array

Array digunakan untuk menyimpan beberapa nilai dalam satu variabel. 

let buah = ["Apel", "Jeruk", "Mangga"];

console.log(buah[0]);       // "Apel"
console.log(buah.length);   // 3

buah.push("Pisang");        // tambah di akhir
buah.pop();                 // hapus dari akhir

46. Method Array

Array punya banyak method untuk mengolah data dengan singkat. 

let angka = [1, 2, 3, 4, 5];

// forEach: menjalankan sesuatu untuk tiap item
angka.forEach((n) => console.log(n));

// map: membuat array baru hasil transformasi
let kali2 = angka.map((n) => n * 2);
console.log(kali2); // [2, 4, 6, 8, 10]

// filter: menyaring item sesuai kondisi
let genap = angka.filter((n) => n % 2 === 0);
console.log(genap); // [2, 4]

// find: mencari item pertama yang cocok
let lebihDari3 = angka.find((n) => n > 3);
console.log(lebihDari3); // 4

// includes: mengecek apakah ada
console.log(angka.includes(3)); // true
  • forEach: Menjalankan fungsi untuk tiap item.
  • map: Mengubah tiap item, hasilnya array baru.
  • filter: Mengambil item yang memenuhi kondisi.
  • find: Mengambil item pertama yang cocok.

47. Object

Object menyimpan data dalam bentuk pasangan property dan value. 

let siswa = {
    nama: "Andi",
    kelas: "PPLG",
    umur: 17
};

console.log(siswa.nama);
siswa.umur = 18;
siswa.hobi = "Coding"; // tambah property baru

48. JSON

JSON adalah format teks untuk menyimpan dan menukar data. Bentuknya mirip object JavaScript, tapi kunci dan teksnya wajib memakai tanda kutip ganda. 

let siswa = { nama: "Andi", umur: 17 };

// Object → teks JSON
let teks = JSON.stringify(siswa);
console.log(teks); // {"nama":"Andi","umur":17}

// Teks JSON → object
let obj = JSON.parse(teks);
console.log(obj.nama); // "Andi"

JSON sering dipakai untuk menyimpan data di LocalStorage dan menerima data dari server.

50. querySelector

querySelector memilih elemen memakai selector CSS, jadi lebih fleksibel daripada getElementById. 

// Elemen pertama yang cocok
let judul = document.querySelector("h1");
let tombol = document.querySelector("#tombol");
let kartu = document.querySelector(".kartu");

// Semua elemen yang cocok
let semuaItem = document.querySelectorAll("li");

semuaItem.forEach((item) => {
    item.style.color = "blue";
});

// Mengubah isi dan class
judul.textContent = "Judul Baru";
judul.classList.add("aktif");
judul.classList.toggle("gelap");
  • querySelector: Mengambil satu elemen pertama.
  • querySelectorAll: Mengambil semua elemen yang cocok.
  • classList: Menambah, menghapus, atau menukar class.

52. setTimeout dan setInterval

Kedua fungsi ini menjalankan kode setelah jeda waktu tertentu (dalam milidetik; 1000 ms = 1 detik). 

// Dijalankan sekali setelah 2 detik
setTimeout(() => {
    console.log("2 detik berlalu");
}, 2000);

// Dijalankan berulang tiap 1 detik
let hitung = 0;

let timer = setInterval(() => {
    hitung++;
    console.log(hitung);

    if (hitung === 5) {
        clearInterval(timer); // hentikan
    }
}, 1000);
  • setTimeout: Menunda, berjalan satu kali.
  • setInterval: Mengulang terus sampai dihentikan.
  • clearTimeout / clearInterval: Menghentikannya.

53. Penanganan Error

try...catch menangkap error agar program tidak langsung berhenti. 

try {
    let data = JSON.parse("teks yang bukan JSON");
    console.log(data);
} catch (error) {
    console.log("Terjadi error:", error.message);
} finally {
    console.log("Selalu dijalankan");
}

// Membuat error sendiri
function bagi(a, b) {
    if (b === 0) {
        throw new Error("Tidak bisa dibagi nol");
    }
    return a / b;
}
  • try: Kode yang mungkin error.
  • catch: Dijalankan jika terjadi error.
  • finally: Selalu dijalankan, ada error atau tidak.
  • throw: Membuat error secara manual.

54. LocalStorage

LocalStorage digunakan untuk menyimpan data sederhana di browser agar tetap tersedia setelah halaman dimuat ulang. 

localStorage.setItem("nama", "Andi");

let nama = localStorage.getItem("nama");

console.log(nama);

localStorage.removeItem("nama");

// Menyimpan object memakai JSON
let siswa = { nama: "Andi", umur: 17 };
localStorage.setItem("siswa", JSON.stringify(siswa));

let data = JSON.parse(localStorage.getItem("siswa"));

LocalStorage hanya bisa menyimpan teks, jadi object dan array harus diubah dulu dengan JSON.stringify.
